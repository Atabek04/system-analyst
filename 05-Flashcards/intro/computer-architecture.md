Coding Questions
В чём разница между ОЗУ и постоянной памятью (HDD/SSD)?
Back:
- **ОЗУ (RAM)** — быстрая (~20 ГБ/с), временная (очищается при выключении), ограниченный объём. Как рабочий стол с открытыми книгами.
- **HDD/SSD** — медленнее (0.1-2 ГБ/с), постоянная (данные сохраняются), большой объём. Как библиотека.
Поток данных: Диск → ОЗУ для обработки → Диск для сохранения.

Coding Questions
Почему процессор не может работать напрямую с жёстким диском?
Back: Несоответствие скоростей. Процессору нужна новая инструкция каждые ~0.3 наносекунды. HDD отдаёт данные каждые ~10 миллисекунд — **в 30 миллионов раз медленнее**. Процессор простаивал бы 99.9999% времени. ОЗУ решает эту проблему, обеспечивая достаточную скорость.

Какова роль операционной системы (ОС) в управлении памятью?
Back: ОС решает, какие данные остаются в ОЗУ, а какие перемещаются на диск. Процессор выполняет инструкции; ОС принимает стратегические решения о распределении ресурсов.
