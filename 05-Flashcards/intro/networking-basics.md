Coding Questions
Что такое DNS и какую проблему он решает?
Back: **DNS** (Domain Name System) переводит человекочитаемые доменные имена (google.com) в IP-адреса (142.250.74.46), которые компьютеры используют для нахождения друг друга. Без DNS пришлось бы запоминать числовые адреса для каждого сайта.

Coding Questions
Какие физические компоненты обеспечивают работу Интернета?
Back:
- **Кабели** (оптоволоконные, медные) — передают данные как световые/электрические сигналы
- **Коммутаторы и маршрутизаторы** (Switches/Routers) — направляют трафик между сетями
- **Репитеры** (Repeaters) — усиливают сигнал на больших расстояниях
- **Подводные кабели** — соединяют континенты через океаны (95%+ межконтинентального трафика)
- **ISP** (провайдеры) — дают доступ к глобальной сети
