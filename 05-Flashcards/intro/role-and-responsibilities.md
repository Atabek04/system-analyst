Back: **Профессиональный стандарт** «Системный аналитик» (код 06.022).

START
Coding Questions
Какого слова нет в названиях трудовых функций профстандарта «Системный аналитик»?
Back: «Программирование». Функции про выявление требований, обследование, ТЗ, изменения и согласование.
Tags: intro role standard
END

START
Coding Questions
Почему управление изменениями требований выделено в профстандарте в отдельную функцию?
Back: Требования меняются, пока система живёт, и каждое изменение задевает модель данных, интеграции и тесты.
Tags: intro role standard
END

START
Coding Questions
Почему «аналитик просто пишет документы» это заблуждение?
Back: Документ это побочный продукт. Работа в том, чтобы найти неопределённость, задать вопросы и договориться.
Tags: intro role misconception
END

START
Coding Questions
Кто решает, какая из двух функций получит бюджет в этом квартале?
Back: **Владелец продукта** или бизнес. Аналитик даёт оценку сложности и рисков, но не выбирает.
Tags: intro role boundary
END

Coding Questions

- **BA**: зачем бизнесу это нужно, как устроен процесс
- **SA**: как должна вести себя система

Coding Questions
Чем менеджер продукта отличается от менеджера проекта?

- **Менеджер проекта**: сроки, бюджет, ресурсы

Back: Она может значить и **менеджера продукта**, и **менеджера проекта**, а это разные работы.

Back: Работа анализа одна, а названий должностей много: системный аналитик, Product Owner, менеджер продукта и другие.

Coding Questions
Какие три вопроса задать на собеседовании вместо «вы ищете системного аналитика?»
Back:
- Кто пишет требования?
- Кто проектирует интеграции?
- Кто решает приоритеты?
Tags: intro role interview
END

START
Coding Questions
По какому вопросу проходит граница между аналитиком и разработчиком?
Back: Аналитик решает, **что** система делает. Разработчик решает, **как** это написано в коде.
Tags: intro role developer
END

START
Coding Questions
Клиент переводит больше денег, чем есть на счёте. Кто решает, какое сообщение он увидит?
Back: **Аналитик**: это решение о поведении системы, у него есть последствия для поддержки, регулятора и других каналов.
Tags: intro role developer
END

Coding Questions
Зачем аналитику SQL, если он не пишет код системы?
Back: Чтобы проверить, какие данные уже есть, и описать модель данных.
Tags: intro role skills
