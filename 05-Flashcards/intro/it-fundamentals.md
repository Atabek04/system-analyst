Coding Questions
Зачем System Analyst понимать основы IT?
Back: Понимание слоёв IT позволяет задавать точные вопросы. Когда пользователь говорит "система медленная", SA с пониманием основ спрашивает: "Медленно при загрузке? Обработке? Это сеть, база данных или процессор?" Без этого SA может лишь передать расплывчатую жалобу разработчикам.

Что значит "режим любопытства" для System Analyst?
Back: Всегда спрашивать **ПОЧЕМУ** — не для запоминания фактов, а чтобы мыслить слоями. Когда компьютер загружается: "Что просыпается первым?" Когда софт падает: "Какой слой отказал?" Это любопытство позволяет видеть проблемы, которые другие пропускают.
