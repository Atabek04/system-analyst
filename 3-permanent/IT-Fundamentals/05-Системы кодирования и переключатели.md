# Машины реагируют на паттерны без понимания их значения

---

## Слайд 1: Системы кодирования — коммуникация через паттерны

**Вопрос:**
> Процессор — это просто кремний и электричество. Когда ОЗУ говорит "сложи 2 + 3" — что физически происходит?

**Сценарий: Два холма ночью**
- Вы на одном холме, друг на другом
- У вас есть фонарик

**Вопрос:**
> Можете ли вы передать сообщение "ПОМОЩЬ", используя только вкл/выкл фонарика?

**Ответ:** Да. Создайте систему кодирования:
- 3 вспышки = опасность
- 5 вспышек = всё в порядке

---

## Слайд 2: Понимает ли фонарик?

**Критический вопрос:**
> Понимает ли фонарик слово "опасность"?

**Ответ:** Нет. Фонарик просто включается/выключается.

**Люди придают паттернам значение.**

**Три компонента:**
- **Отправитель** → создаёт паттерн
- **Инструмент (фонарик)** → передаёт сигналы вкл/выкл
- **Получатель** → интерпретирует паттерн

---

## Слайд 3: Машинные реакции без понимания

**Вопрос:**
> Замените друга машиной, которая звонит в колокол после обнаружения 3 вспышек. Понимает ли она "опасность"?

**Ответ:**
- Нет. Она **реагирует на паттерн**
- Реакция ≠ понимание

---

## Слайд 4: Построение памяти без мозга

**Цель:** Создать машину, которая звонит в колокол после ровно 3 вспышек

**Компоненты:**
- **Датчик света** (знает: "свет СЕЙЧАС? да/нет" — нет памяти прошлого)
- **Переключатели** (две позиции: ВКЛ или ВЫКЛ)
- **Колокол**

**Вопрос:**
> Датчик света не может запомнить. Как использовать переключатели для отслеживания "сколько вспышек было"?

**Подсказка:** Каждый переключатель может хранить одну порцию информации (вкл/выкл)

**Вопрос:**
> Сколько переключателей нужно для счёта до 3?

**Ответ:** 3 переключателя

---

## Слайд 5: Механизм счёта

**Как это работает:**
```
Старт: Переключатель1=ВЫКЛ, Переключатель2=ВЫКЛ, Переключатель3=ВЫКЛ

Вспышка 1 → Переключатель1: ВЫКЛ→ВКЛ
Вспышка 2 → Переключатель2: ВЫКЛ→ВКЛ
Вспышка 3 → Переключатель3: ВЫКЛ→ВКЛ → Все три ВКЛ → Колокол звонит
```

**Ключевое понимание:**
- Переключатели хранят состояние
- Паттерн состояний = информация
- Конкретный паттерн = запускает действие

**Интеллект не нужен. Только физические изменения состояния.**
