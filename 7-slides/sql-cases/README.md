# SQL Практика: 5 Случаев для Студентов

Каждый студент получает **один уникальный случай** для практики SQL команд. Все 6 команд одинаковые (CREATE, INSERT, SELECT, ALTER, UPDATE, DELETE), но контекст разный.

## Структура каждого случая

### 1. **Контекст** — почему это нужно
Бизнес-сценарий в реальном мире. Почему данные нужны администратору/владельцу.

### 2. **Таблицы** — 2–3 таблицы со схемой
Каждая таблица описана:
- Названия столбцов
- Типы данных (INT, VARCHAR, DATE, DECIMAL, BOOLEAN)
- Примечания к каждому полю

### 3. **Примеры данных** — готовые INSERT VALUES
5–6 строк реальных данных, чтобы студент мог сразу вставить и работать.

### 4. **Практические задачи** — упражнения на все 6 команд
- CREATE TABLE (1–2 задачи)
- INSERT INTO (готовые данные)
- SELECT (3–4 задачи)
- ALTER TABLE (1 задача)
- UPDATE (2 задачи)
- DELETE (2 задачи)

### 5. **Бизнес-вопросы** — для SELECT с фильтрацией/агрегацией
"Сколько...", "Кто...", "Какой...". Готовые вопросы для фильтрации.

## Как использовать в уроке

### **Вариант 1: Один случай для всех** ⏱️ 60 мин
1. Выбери ОД случай (например, Case A — Ресторан)
2. Все студенты выполняют одни и те же задачи
3. Конкурс: кто быстрее и правильнее

### **Вариант 2: Разные случаи на студента** ⏱️ 90 мин
1. Раздай каждому свой случай
2. Студенты работают независимо, но на одинаковые команды
3. В конце: каждый показывает результаты
4. Преимущество: разные контексты → разные данные → сложнее списать

### **Вариант 3: Групповой проект** ⏱️ 120 мин
1. Разделить на пары (5 студентов → можно группы по 2–3)
2. Каждой группе — свой случай
3. Вместе создают и заполняют БД
4. Презентация результатов

## Расширение (без relationships, но multi-table)

Каждый случай готов к многотабличным запросам:

**Case A (Ресторан):**
- Какие блюда заказали сегодня? (JOIN dishes с daily_orders)
- Сколько денег от каждого блюда? (SUM, GROUP BY)

**Case B (Библиотека):**
- Какие книги сейчас на руках? (WHERE returned_date = NULL)
- Какой автор самый популярный? (GROUP BY, COUNT)

**Case C (Школа):**
- Средняя оценка по классам? (GROUP BY grade, AVG)
- Кто получил двойку и по какому предмету? (JOIN)

**Case D (Клиника):**
- Расписание врача на день? (WHERE doctor_name AND appointment_date)
- Сколько времени врач потратил на приёмы? (SUM duration_min)

**Case E (Фриланс):**
- Кто заработал больше всего? (ORDER BY total_earnings DESC)
- Средний рейтинг за специальность? (GROUP BY, AVG)

## Советы учителю

1. **Время на задачу:** 3–5 мин на CREATE/INSERT, 5–7 мин на SELECT, 10–15 мин на UPDATE/DELETE
2. **Проверка:** попроси студентов показать результаты SELECT после каждой операции
3. **Ошибки:** помощь только на WHERE и синтаксис, остальное — самостоятельно
4. **Вариант сложнее:** добавь требование — "без WHERE — почему опасно?"
5. **Соревнование:** "кто первый завершит все 6 команд?" → премия 🏆
