# Случай C: Школа

## Контекст
Школе нужна база данных для учёта студентов и оценок. Директору нужно видеть какие студенты учатся, какие оценки по предметам, кто отличник а кто на грани отчисления.

---

## Таблица 1: students (Ученики)

```
id              INT (ID студента)
full_name       VARCHAR(150) (полное имя)
grade           INT (класс: 9, 10, 11)
enrollment_date DATE (дата поступления)
is_active       BOOLEAN (учится ли сейчас)
gpa             DECIMAL(3, 2) (средний балл: от 2.0 до 5.0)
```

## Таблица 2: grades (Оценки студентов)

```
id            INT (ID записи об оценке)
student_id    INT (какой ученик — ссылка на students.id)
subject       VARCHAR(100) (предмет: "Математика", "Английский")
score         INT (оценка от 2 до 5)
exam_date     DATE (дата экзамена/контроля)
exam_type     VARCHAR(50) (тип: "Контрольная", "Экзамен", "Тест")
```

## Практические задачи

### 1. CREATE TABLE
Создай таблицы `students` и `grades`.

### 2. INSERT INTO
Вставь примеры данных.

### 3. SELECT (Выборки)
- Выведи всех активных студентов (is_active = true)
- Выведи только имена и классы всех студентов
- Выведи все оценки по Математике

### 4. SELECT WHERE (Фильтрация)
- Найди всех студентов 10 класса
- Найди всех отличников (gpa >= 4.5)
- Найди двойки (score = 2)

### 5. ALTER TABLE
Добавь столбец `attendance_percent` (INT, процент посещаемости) в таблицу students.

### 6. UPDATE
- Обнови GPA для Алексея на 4.60
- Установи is_active = false для всех студентов с GPA < 2.8

### 7. DELETE
- Удали оценку с id = 5
- Удали всех неактивных студентов (is_active = false)

### Бизнес-вопросы (для SELECT)
1. Сколько активных студентов в школе?
2. Сколько студентов в каждом классе?
3. Какой предмет самый сложный? (средняя оценка за предмет)
4. Кто получил двойку? (по имени)
5. Сколько контрольных работ было написано?
6. Средняя оценка в школе?
