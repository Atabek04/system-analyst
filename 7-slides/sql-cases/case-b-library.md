# Случай B: Библиотека

## Контекст
Городская библиотека нужна база для учёта книг и кто что взял. Библиотекарю нужно знать какие книги есть, кто взял какую книгу, когда нужно вернуть.

---

## Таблица 1: books (Книги в библиотеке)

```
id           INT (ID книги)
title        VARCHAR(200) (название: "Война и мир")
author       VARCHAR(150) (автор)
year         INT (год издания)
genre        VARCHAR(50) (жанр: "Фантастика", "Классика", "Детская")
copies       INT (сколько копий в библиотеке)
isbn         VARCHAR(20) (номер ISBN)
```

## Таблица 2: borrowings (Выдача книг читателями)

```
id            INT (ID записи о выдаче)
book_id       INT (какую книгу взяли — ссылка на books.id)
reader_name   VARCHAR(100) (имя читателя)
borrowed_date DATE (дата выдачи)
due_date      DATE (дата возврата)
returned_date DATE (когда вернули, NULL если ещё не вернул)
```

## Практические задачи

### 1. CREATE TABLE
Создай таблицы `books` и `borrowings`.

### 2. INSERT INTO
Вставь примеры данных.

### 3. SELECT (Выборки)
- Выведи все книги фантастики
- Выведи только названия авторов и год издания
- Выведи все выданные книги (все записи из borrowings)

### 4. SELECT WHERE (Фильтрация)
- Найди все книги, изданные после 1950 года
- Найди все книги с более чем 2 копиями (copies > 2)
- Найди все выдачи, которые ещё не вернули (returned_date = NULL)

### 5. ALTER TABLE
Добавь столбец `rating` (INT от 1 до 5) — читатели оценивают книги.

### 6. UPDATE
- Обнови количество копий "Маленького принца" на 6 (book_id = 3)
- Установи дату возврата для всех нарушителей (due_date < сегодня и returned_date = NULL)

### 7. DELETE
- Удали выдачу (borrowing) с id = 2
- Удали все книги, которых нет в наличии (copies = 0)

### Бизнес-вопросы (для SELECT)
1. Сколько разных читателей брали книги?
2. Какая книга самая популярная? (какую брали чаще всего)
3. Сколько книг сейчас на руках (не возвращено)?
4. Кто нарушил сроки возврата? (due_date < returned_date)
5. Какие книги есть в 3+ копиях?
