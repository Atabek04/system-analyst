# Случай D: Клиника

## Контекст
Частная клиника нужна система для управления пациентами и приёмами у врачей. Администратору нужно видеть расписание врачей, кто записан на приём, сколько пациентов за день.

---

## Таблица 1: patients (Пациенты)

```
id                INT (ID пациента)
full_name         VARCHAR(150) (ФИО)
phone             VARCHAR(20) (номер телефона)
date_of_birth     DATE (дата рождения)
insurance_number  VARCHAR(50) (номер страховки)
is_active         BOOLEAN (активный пациент)
registration_date DATE (дата регистрации в клинике)
```

## Таблица 2: appointments (Приёмы у врачей)

```
id              INT (ID приёма)
patient_id      INT (какой пациент — ссылка на patients.id)
doctor_name     VARCHAR(100) (врач: "Доктор Иван", "Доктор Мария")
specialty       VARCHAR(50) (специальность: "Кардиолог", "Терапевт")
appointment_date DATETIME (дата и время приёма)
duration_min    INT (продолжительность в минутах)
status          VARCHAR(20) ("Запланирован", "Завершён", "Отменён")
notes           TEXT (примечания врача)
```

## Практические задачи

### 1. CREATE TABLE
Создай таблицы `patients` и `appointments`.

### 2. INSERT INTO
Вставь примеры данных.

### 3. SELECT (Выборки)
- Выведи всех активных пациентов
- Выведи только ФИО и номер телефона
- Выведи все планируемые приёмы (status = "Запланирован")

### 4. SELECT WHERE (Фильтрация)
- Найди приёмы у кардиолога
- Найди всех пациентов, зарегистрировавшихся в марте (registration_date >= 2024-03-01)
- Найди пациентов старше 40 лет

### 5. ALTER TABLE
Добавь столбец `last_appointment_date` (DATE) в patients — дата последнего приёма.

### 6. UPDATE
- Измени статус приёма с id = 1 на "Завершён"
- Установи is_active = false для всех неактивных пациентов (которые не пришли — status = "Отменён" 2+ раза)

### 7. DELETE
- Удали приём с id = 5
- Удали неактивных пациентов (is_active = false)

### Бизнес-вопросы (для SELECT)
1. Сколько приёмов запланировано на завтра?
2. Какой врач самый загруженный? (больше приёмов)
3. Сколько пациентов зарегистрировано в клинике?
4. Какая специальность самая популярная?
5. Среднее время приёма по врачам?
6. Сколько приёмов завершено (status = "Завершён")?
