# Случай A: Ресторан

## Контекст
Маленький ресторан нужна система управления меню и заказами. Шефу нужно отслеживать какие блюда популярны, сколько заказов в день, сколько денег заработано.

---

## Таблица 1: dishes (Блюда в меню)

```
id          INT (уникальный номер блюда)
name        VARCHAR(150) (название блюда: "Борщ", "Плов")
category    VARCHAR(50) (категория: "Супы", "Основное", "Десерты")
price       DECIMAL(10, 2) (цена в тенге)
available   BOOLEAN (есть ли блюдо в наличии сегодня)
prep_time   INT (время приготовления в минутах)
```

## Таблица 2: daily_orders (Заказы за день)

```
id           INT (номер заказа)
order_time   TIMESTAMP (когда заказали)
dish_id      INT (какое блюдо заказали — ссылка на dishes.id)
quantity     INT (сколько порций)
table_num    INT (номер стола)
total_price  DECIMAL(10, 2) (сумма за этот заказ)
```

## Практические задачи

### 1. CREATE TABLE
Создай обе таблицы `dishes` и `daily_orders` с указанными полями и типами.

### 2. INSERT INTO
Вставь примеры данных из таблицы выше.

### 3. SELECT (Основные запросы)
- Выведи все доступные блюда (`available = true`)
- Выведи только названия и цены всех блюд
- Выведи все заказы, сделанные после 13:00

### 4. SELECT WHERE (Фильтрация)
- Найди все блюда дороже 2000 тенге
- Найди все блюда категории "Основное"
- Найди заказы на столе 5 (table_num = 5)

### 5. ALTER TABLE
Добавь столбец `chef_special` (BOOLEAN) — отмечаем фирменные блюда.

### 6. UPDATE
- Обнови цену борща на 1300 тенге (id = 1)
- Установи все блюда категории "Десерты" как недоступные (available = false)

### 7. DELETE
- Удали заказ с id = 4
- Удали все блюда с временем приготовления > 30 минут

### Бизнес-вопросы (для SELECT)
1. Сколько заказов было сегодня? (COUNT)
2. Какое блюдо самое дорогое?
3. Сколько денег заработано за день? (SUM total_price)
4. Какое блюдо заказали чаще всего? (GROUP BY dish_id, COUNT)
