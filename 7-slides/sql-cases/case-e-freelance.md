# Случай E: Фриланс-платформа

## Контекст
Онлайн-платформа для фрилансеров и заказчиков. Администратору нужно видеть кто какие проекты выполняет, сколько зарабатывает, кто самый рейтинговый фрилансер.

---

## Таблица 1: freelancers (Фрилансеры)

```
id              INT (ID фрилансера)
full_name       VARCHAR(150) (имя)
specialization  VARCHAR(100) (специализация: "Веб-разработка", "Дизайн", "Копирайтинг")
hourly_rate     DECIMAL(10, 2) (ставка в USD/час)
rating          DECIMAL(3, 1) (рейтинг от 1 до 5)
total_earnings  DECIMAL(15, 2) (всего заработано)
is_available    BOOLEAN (доступен ли для новых проектов)
joined_date     DATE (дата присоединения)
```

## Таблица 2: projects (Проекты)

```
id                INT (ID проекта)
freelancer_id     INT (кто выполняет — ссылка на freelancers.id)
project_name      VARCHAR(200) (название проекта)
description       TEXT (описание)
budget            DECIMAL(12, 2) (бюджет в USD)
estimated_hours   INT (примерное количество часов)
status            VARCHAR(30) ("В работе", "Завершён", "На паузе", "Отменён")
start_date        DATE (дата начала)
deadline          DATE (дата сдачи)
client_rating     DECIMAL(3, 1) (оценка клиента после завершения)
```

## Практические задачи

### 1. CREATE TABLE
Создай таблицы `freelancers` и `projects`.

### 2. INSERT INTO
Вставь примеры данных.

### 3. SELECT (Выборки)
- Выведи всех доступных фрилансеров (is_available = true)
- Выведи только имена и специализацию
- Выведи все проекты в статусе "В работе"

### 4. SELECT WHERE (Фильтрация)
- Найди всех веб-разработчиков
- Найди фрилансеров с рейтингом >= 4.5
- Найди проекты с бюджетом > 2000 USD

### 5. ALTER TABLE
Добавь столбец `completion_date` (DATE) в projects — дата фактического завершения.

### 6. UPDATE
- Обнови статус проекта с id = 3 на "Завершён"
- Установи is_available = false для всех фрилансеров с 3+ проектами "В работе"

### 7. DELETE
- Удали проект с id = 5
- Удали всех недавних фрилансеров (joined_date < 2023-06-01 и total_earnings < 5000)

### Бизнес-вопросы (для SELECT)
1. Кто самый рейтинговый фрилансер? (rating максимум)
2. Сколько денег платят за проекты в среднем? (AVG budget)
3. Какая специализация самая популярная?
4. Кто заработал больше всего? (по total_earnings)
5. Сколько проектов в процессе?
6. Какой фрилансер выполнил больше всего проектов? (COUNT)
7. Средний рейтинг проектов для каждого фрилансера?
