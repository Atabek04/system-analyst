Как делится рынок

📚 Контент-школы

systemanalyst.life продаёт по-курсам — широко, но дробит студентов: купил одну тему и ушёл. Широта есть, цельности и платформы нет.

🎓 Live-буткемпы

OTUS / Netology / Skillbox — live-first: сильная вовлечённость, но расписание теряет 30–40% покупателей, а costs растут линейно с числом преподавателей.

🤖 AI-native (мы)

Здесь никого нет. Видео в своём темпе + AI в каждом уроке + слой подотчётности. First-mover в позиции, которую не занял ни один игрок.

5 · SWOT

Честный разбор — слабости реальны и учтены, а не спрятаны.

💪 Сильные стороны

  • Единственная на RU-рынке платформа с полностью встроенным AI
  • Самая глубокая программа: SQL / API / архитектура / observability
  • Свой темп + интервальные повторения + геймификация структурно решают проблему доходимости
  • SQL-песочница и задания «что не так?» — ни у кого нет
  • Полный цикл SA: Strategy Analysis → UAT

⚠️ Слабые стороны

  • Нет узнаваемости бренда
  • Нет сети выпускников / партнёров по найму на старте
  • AI-проверка артефактов технически сложна — риск качества вначале
  • Зависимость от одного преподавателя на старте
  • Платформу надо построить до продаж → затраты вперёд

🚀 Возможности

  • AI-native платформы на RU SA-рынке нет — широкий коридор first-mover
  • Модель «купи курс» дробит студентов; мы даём единый путь
  • AI-симуляция и голосовое интервью — пустые ниши в RU EdTech
  • Авто-синхрон флешкарт — этого не делает никто
  • Реальный дефицит SA → партнёрства по трудоустройству

🛡️ Угрозы

  • У systemanalyst.life есть каталог + бренд + community
  • OTUS держит Senior / enterprise-глубину
  • Строить платформу медленнее, чем записывать курсы — конкуренты выпускают контент, пока мы строим
  • Стоимость AI API давит на юнит-экономику при малом масштабе
  • CBAP/PMI-PBA забирают мотивированных профи мимо буткемпов
Честная версия: мы pre-revenue, pre-alumni, pre-platform против устоявшихся школ. Ров — это видение AI-фич + глубина программы, и этот ров реален только когда построен и запущен. Поэтому: сначала проверяем вручную, потом строим AI-преимущество.

📊 Что говорит рынок

  • Пол ≈ 110 000 ₽ · улица ≈ 93–120k · потолок ≈ 215k
  • Покупатель сравнивает ежемесячный платёж, а не сумму (3 000–5 000 ₽/мес на 24–36 мес)
  • «−50%» — постоянный якорь, прайс это фикция
  • Гарантия делит рынок: Skillbox/GeekBrains — «работа или возврат»; OTUS/Yandex — только помощь
  • Диапазон мини-курса: 30–55k ₽ за тему

🎯 Наша позиция по цене

  • Флагман ~109 000 ₽ — уверенный mid-market, ниже прайса Skillbox/Netology, выше пола; AI-ров оправдывает
  • Мини-курс ~19 900 ₽ — дешевле самой дешёвой единицы рынка → лёгкое первое «да»
  • Халяльная рассрочка (ijarah) — фиксированная сумма при подписании, без процентов и пеней; в шапке — месячный платёж
  • Cohort 0 по 59 000 ₽ × 10–15 основателей → отзывы + кейс, затем поднимаем
  • На старте без денежной гарантии → условное обязательство «коучинг до трудоустройства»
