Как DNS решает проблему того, что браузер не знает адрес сервера при вводе имени сайта?	DNS переводит доменное имя (youtube.com) в IP-адрес (142.250.80.78), который браузер использует для подключения к серверу. DNS — это распределённая база данных, «телефонная книга интернета». Браузер → DNS: "Где 'youtube.com'?" → DNS → Браузер: "youtube.com = 142.250.80.78" → Браузер подключается к этому IP-адресу.
Почему при глобальном крахе DNS вы не сможете открыть facebook.com, но серверы Facebook будут работать нормально?	Серверы Facebook работают идеально, но браузер не может узнать их IP-адрес без DNS. DNS не хранит данные сайтов — только адреса. Если вы знаете IP напрямую (например, 157.240.22.35), можете ввести его в браузер и подключиться. DNS переводит имена → адреса, но не влияет на работу самих серверов.
В чём разница между сервером и обычным компьютером?	Сервер — это обычный компьютер (процессор, RAM, диск — всё как у ноутбука). Ключевые отличия: 1) Работает 24/7 без выключения, 2) Более мощный (больше процессоров, 64-512 GB RAM, больше дисков), 3) Находится в дата-центре (специальное помещение с охлаждением, бесперебойным питанием), 4) Может обслуживать тысячи клиентов одновременно. Никакой магии — просто компьютер, который ВСЕГДА включён и ждёт запросы.
Как сетевой свитч решает проблему «спагетти из кабелей» в офисе со 100 компьютерами?	Без свитча: 100 компьютеров требуют ~5000 кабелей (каждый компьютер → 99 кабелей к остальным). Со свитчем: каждый компьютер подключается ОДНИМ кабелем к свитчу. Свитч — центральное устройство, которое умно маршрутизирует сообщения между компьютерами. 100 компьютеров = 100 кабелей вместо 5000. Аналогия: удлинитель с множеством розеток.
Почему стандартный Ethernet кабель не подходит для передачи данных между городами?	Ethernet кабель передаёт электрический сигнал максимум ~100 метров — после этого сигнал слишком слабый для надёжного чтения. Расстояние между городами: 10,000+ метров. Для больших расстояний нужны другие технологии: оптоволокно (световые импульсы слабеют медленнее) и репитеры (усиливают сигнал каждые 40-80 км).
В чём ключевое техническое различие между медными и оптоволоконными кабелями для интернета?	Скорость передачи почти одинакова (~200,000 км/с для обоих — свет и электричество движутся с похожей скоростью). Ключевое различие — дальность без ослабления. Медь (Ethernet): электрический сигнал умирает через ~100 метров. Оптоволокно: световые импульсы проходят 40+ километров без значительного ослабления. Применение: дом = Ethernet (короткие расстояния), между городами = оптоволокно (большие расстояния).
Как работают репитеры в цепочке оптоволоконных кабелей на расстоянии 1000+ км?	Репитеры размещаются каждые 40-80 км. Процесс: 1) Получают слабый сигнал, 2) Читают данные (распознают паттерны 1 и 0), 3) Генерируют новый сильный сигнал и отправляют дальше. Аналогия: эстафетный бег — уставший бегун передаёт эстафету свежему бегуну. Данные «перепрыгивают» 1000+ км через цепочку репитеров, каждый усиливает сигнал для следующего участка.
Откуда подводные репитеры в океане (5000+ км от берега) получают электропитание?	От самого кабеля — он выполняет ДВЕ задачи одновременно: 1) Передача данных (световые импульсы через оптоволоконные жилы внутри кабеля), 2) Передача электричества (через медные жилы в том же кабеле). Станции на берегу отправляют высоковольтное питание по кабелю. Репитеры получают питание и усиливают сигнал каждые ~50-100 км. Один кабель = данные + энергия.
Почему ISP (интернет-провайдеры) берут ежемесячную плату за доступ к интернету?	ISP вложили миллиарды долларов в инфраструктуру: прокладка подводных кабелей через океаны, оптоволокно под каждой улицей города, сетевые свитчи, репитеры каждые 40-80 км, обслуживание при поломках. ISP владеют «шоссе данных» (физической инфраструктурой) и берут плату за её использование — как платная дорога. Без оплаты нет доступа к их сети.
Как конкуренция между несколькими ISP решает проблему монополии в телеком-индустрии?	Проблема монополии: одна компания владеет всеми кабелями → контроль цен, плохой сервис, нет выбора для клиентов. Решение: несколько ISP в каждой стране конкурируют за клиентов (предлагают лучшие цены, скорость сервиса), соединяют свои сети друг с другом (обеспечивают доступ ко всему интернету), государственное регулирование предотвращает захват рынка одной компанией.
Проследите полный путь запроса от ввода google.com до отображения страницы в браузере.	1) Браузер → DNS-запрос: "Где google.com?" 2) DNS → Ответ: "IP-адрес 142.250.185.46" 3) Браузер → Ethernet кабель → Свитч в офисе/доме → ISP кабели 4) ISP сеть → Оптоволокно между городами → Репитеры усиливают сигнал каждые 40-80 км 5) Достигает сервера Google по IP-адресу 6) Сервер Google отправляет ответ (HTML-страницу) обратно тем же путём 7) Данные → Репитеры → ISP → Свитч → Ваш компьютер → Браузер парсит HTML и отображает страницу.
В чём разница между тем, что передавали телефонные кабели изначально и сейчас?	Физический носитель одинаков (медные провода), различие в паттернах электрических сигналов. Изначально (1800-е): телефон передавал сигналы голоса (вибрации звука, преобразованные в электрические колебания). Сейчас: тот же медный кабель передаёт сигналы данных (двоичный код, паттерны 1 и 0). Ключевой момент: можно использовать старую телефонную инфраструктуру для интернета, просто меняя паттерны сигналов.
Почему оптоволокно используется между городами, а не внутри дома?	Практичность и стоимость. Внутри дома/офиса: расстояния маленькие (~10-100 метров), медного Ethernet кабеля достаточно, проще монтировать, дешевле. Между городами: расстояния огромные (10-100+ км), медный сигнал умирает через 100 метров, оптоволокно проходит 40+ км без ослабления, требует меньше репитеров (экономия на инфраструктуре на больших расстояниях).
Как подводный кабель одновременно передаёт данные и питает репитеры?	Комбинированная конструкция кабеля: внутри оптоволоконные жилы (передают световые импульсы = данные) + медные жилы (передают высоковольтное электричество = питание для репитеров). Станции на берегах отправляют питание по медным жилам. Репитеры в океане получают электричество из кабеля и усиливают световые сигналы данных. Один физический кабель = два независимых канала (данные + энергия).
Почему браузер не может подключиться к youtube.com без DNS, даже если серверы YouTube работают?	Браузер знает только имя "youtube.com", но не знает IP-адрес (142.250.80.78). Без DNS браузер не может узнать, куда отправить запрос. Аналогия: вы знаете имя друга, но не знаете его домашний адрес — не можете отправить письмо. Серверы YouTube работают идеально, но браузер не может их найти в сети без «телефонной книги» (DNS), которая переводит имена → адреса.
Сколько кабелей нужно для подключения 3 компьютеров напрямую друг к другу (каждый с каждым)?	3 кабеля: A ↔ B, B ↔ C, A ↔ C. Формула для n компьютеров: n×(n-1)/2 кабелей. Для 3 компьютеров: 3×2/2 = 3. Для 100 компьютеров: 100×99/2 = 4,950 кабелей. Эта «спагетти» из проводов непрактична — поэтому изобрели сетевой свитч (центральное устройство, каждый компьютер → 1 кабель → свитч).
Что происходит когда электрический сигнал проходит более 100 метров по медному Ethernet кабелю?	Сигнал деградирует и становится слишком слабым для надёжного чтения. Причины ослабления: сопротивление меди (часть энергии превращается в тепло), электромагнитные помехи от других проводов, ёмкость кабеля (заряды просачиваются). После ~100 метров сигнал настолько слаб, что принимающая схема не может надёжно различить 0 и 1. Для больших расстояний нужны репитеры или оптоволокно.
