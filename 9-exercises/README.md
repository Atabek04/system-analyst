# 🧪 Практика: от UI к API (DB + endpoints)

Три упражнения, где студент по готовому интерфейсу восстанавливает **модель данных** и **контракт API**. Закрепляет урок «Как Frontend получает данные от Backend через эндпойнты».

## Задача студента

По макетам приложения и текстовым требованиям написать:
1. **Сущности БД** — таблицы и поля.
2. **Endpoints** — метод, путь, тело запроса и пример тела ответа (JSON) для каждого экрана.

## Три кейса

| Кейс | Приложение | Что тренирует |
|---|---|---|
| **A** | 🍕 Tamak — доставка еды | `GET`, `POST` · массив объектов · вложенные массивы · `null`, `boolean` · `201`+id |
| **B** | ✔ TaskFlow — доска задач | `POST`, `PATCH`, `DELETE` · `204 No Content` · массив меток · чек-лист с `boolean` |
| **C** | 🏝 Stayly — бронирование | `GET` с query · **пагинация** (объект-обёртка) · массив строк · вложенный объект `host` |

Вместе покрывают все 4 HTTP-метода и все ходовые формы JSON-тела в ответе.

## Структура папок

```
case-a-food-delivery/   (и b, c)
├── *.html          ← интерактивный прототип (открой index.html / board.html)
├── styles.css
├── exercise.md     ← задание для студента → импорт в Notion
├── solution.md     ← эталонное решение (только для преподавателя)
└── assets/         ← скриншоты экранов (встроены в exercise.md)
```

## Как показать прототип

Скриншоты уже встроены в `exercise.md`. Если нужен **живой кликабельный** прототип:

```bash
node 9-exercises/serve.js
```

Затем открыть `http://localhost:8778/case-a-food-delivery/index.html` (или `case-b-kanban/board.html`, `case-c-booking/index.html`). Можно и просто открыть `index.html` двойным кликом.

## Импорт в Notion

Импортировать в Notion нужно только `exercise.md` каждого кейса (три отдельные страницы). `solution.md` держать отдельно, не выдавать студентам. Скриншоты из `assets/` подхватятся при импорте, если папка рядом.

## Как проводить

1. Выдать студенту `exercise.md` (Notion) + доступ к прототипу.
2. Дать время на модель данных и endpoint.
3. Разобрать вместе, сверяя с `solution.md`. Оценивать логику, а не дословные имена полей.
4. Порядок сложности: A → B → C.
